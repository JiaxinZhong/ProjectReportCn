\section{引用代码中的某一行}
在正文中引用某代码（如代码~\ref{code:matlab:absorp}~中的第~\ref{line:alpha_Np}~行），需要在代码中相应行的末尾加上注释 \verb|`\label{line:alpha_Np}`|，然后在正文中使用 \verb|\ref{line:alpha_Np}| 即可。
